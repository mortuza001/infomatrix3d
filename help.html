This user manual follows the exact sequence of the InfoMatrix Dashboard (v1.16.1) interface to help you configure your LED display.

🔘 1. Global Focus Control

Located at the top for immediate access.

  • Start/Stop Focus Mode: Manually triggers the Pomodoro timer. This overrides your normal rotation and starts the "Work" countdown set in the Focus Timer section.

📈 2. Market Ticker Configuration

This section manages financial data and visual representation.

  • Stock Symbols: Enter symbols using Yahoo Finance formatting.
    • Standard Stocks: AAPL, TSLA, NVDA.
    • Crypto: BTC-USD, ETH-EUR, DOGE-USD.
    • Forex: CAD=X, EURUSD=X.
    • Commodities: GC=F (Gold), CL=F (Crude Oil).
  • Graph Range: The time window for the chart.
    • Example: 1h (1 Hour), 1d (1 Day), or livegrid (Text list with no graphs).
  • Graph Type: Choose between Line, CandleStick, or Both (alternates between the two).
  • Logo (Checkbox): Displays the asset icon. Requires a reboot to initialize the first time.
  • 4Split (Checkbox): Divides the screen into 4 small quadrants to show 4 tickers at once.
  • .US (Checkbox): Optimizes data fetching for the US Stock Market.
  • Finnhub API Key: Get a free key at finnhub.io. This enables real-time price "wiggling".
  • Exchange: Only available if a Finnhub key is present. Select your preferred crypto venue (e.g., BINANCE, COINBASE).
  • TwelveData API Key: Get a free key at twelvedata.com. Used as high-quality secondary data for OHLC graphs.
  • Stock Alerts: Set visual triggers that make the screen flash.
    • Example: TSLA > 300, BTC-USD < 45000.
  • Custom Display Names: Rename tickers for the screen using the >> separator.
    • Example: BTC-USD >> BITCOIN, GC=F >> GOLD.

🏆 3. Sports Tracker

Input 3-letter city or team codes.

  • NBA / EPL / NFL / NHL / MLB: Enter specific teams separated by commas, or enter ALL to track every live game in that league.
    • Example: TOR, LAL, GSW or ARS, LIV, MUN.
  • Cricket Team or Series: Search by specific country or tournament keywords.
    • Example: ENGLAND, ICC, or TOP.

🚗 4. Commute Configuration

Calculates travel time using the Google Routes API.

  • Google Routes API Key: Required for this module to function.
  • Origin / Destination: Enter street addresses or specific Latitude/Longitude coordinates.
  • Transport Mode: Choose Car, Bus, Subway, or Train.
  • Active Window: Sets the hours (0-23) the commute info appears.
    • Example: 7 to 9 (Morning commute only).
  • Station Address: Only appears if Train is selected. Input your local station for "Park & Ride" calculations.

☁️ 5. City Weather

  • City Weather: Enter in City, CountryCode format.
    • Example: Toronto, CA or London, GB.
  • Temp Units: Select Celsius (°C) or Fahrenheit (°F).
  • Timezone: Your UTC offset.
    • Example: -5 for EST, 0 for GMT.

💬 6. Message Configuration

Configure up to 3 custom rows of info.

  • Mode: Select Text (static message) or RSS (scrolling feed).
  • Value: Enter your custom text or a full RSS URL (e.g., a news site link).
  • Color: Use the color picker to set the text color for that specific row.

⏱️ 7. Focus Timer (Pomodoro)

  • Work (min): Duration of the focus period. Default: 25.
  • Break (min): Duration of the rest period. Default: 5.

🌙 8. Brightness & Schedule

  • Brightness Slider: Master LED intensity (5-255).
  • Night Mode (Checkbox): Enables scheduled dimming.
  • Dim Between: Set start/end hours (e.g., 22 to 7).
  • Night Brightness: Set a lower intensity for the night window.

⏲️ 9. Cycle Durations

Sets how many seconds each module stays on screen.

  • Example: 60 for Stocks, 10 for Weather, 30 for NBA scores.

🖼️ 10. Upload Animation (GIF)

  • Matrix Size: Choose your hardware size (128x64, 80x40, or 64x32).
  • Resize Mode:
    • Stretch: Forces GIF to fill the whole screen.
    • Fit: Maintains aspect ratio with black bars.
    • Crop: Fills screen by cutting off edges.
  • Drop Zone: Drag and drop your GIF here to process it into a matrix-ready .bin file.

🛠️ 11. System Controls

  • Save Configuration: Saves all values to the ESP32. Updates take effect immediately.
  • Reboot Device: Performs a hardware reset. Necessary after changing Logo or Sports settings.
