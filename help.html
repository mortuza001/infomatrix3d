Dashboard Manual

Configure tickers, sports scores, commute routes, weather, custom messages, GIF animations, custom apps, and display controls from your browser.

Open the dashboard from any browser on your network using the display's IP address (e.g., http://192.168.0.15).

1. Focus Mode

Located at the top of the dashboard for immediate access.

  • Start/Stop Focus Mode: Manually triggers the Pomodoro timer, overriding your normal content rotation and starting the Work countdown configured in the Focus Timer section.
  • Physical Button Shortcut: Can also be toggled without opening the dashboard by holding the physical device button for 4 seconds.

2. Visualizer Mode

Transform your matrix into a reactive music effect display.

  • Start/Stop Visualizer: Activates the DDP listener, overriding standard rotation to prioritize high-speed pixel data streaming.
  • LedFx Integration: Once enabled, use tools like LedFx to stream audio effects, manage pixel mapping, and sync lights to music.
  • Detailed Guide: Visit the Visualizer Setup Guide for connection steps and performance tuning.

3. Market Ticker Configuration

Manages financial data symbols, chart styles, alerts, and visual layout.

  • Stock Symbols: Enter symbols using Yahoo Finance formatting:
    • Standard Stocks: AAPL, TSLA, NVDA, SU.TO, BP.L
    • Crypto: BTC-USD, ETH-EUR, DOGE-USD
    • Forex: CAD=X, EURUSD=X
    • Commodities: GC=F (Gold), CL=F (Crude Oil)
    • Index: ^GSPC (S&P 500), ^DJI (Dow 30)
  • Graph Range: Sets the chart time window (e.g., 1h for 1 Hour, 1d for 1 Day, or Grid for a text list without graphs).
  • Graph Type: Choose Line, CandleStick, or Both (alternates between line and candlestick views).
  • Logo (Checkbox): Displays the asset icon. Requires a reboot when initializing for the first time.
  • 4Split (Checkbox): Splits the display into 4 quadrants to show 4 tickers simultaneously (available on the X12-128 model).
  • .US (Checkbox): Optimizes crypto data fetching for U.S. regulatory requirements.
  • Finnhub API Key: Free key from finnhub.io to enable real-time price updates.
  • Exchange: Available when a Finnhub key is set; choose your preferred crypto exchange (e.g., BINANCE, COINBASE).
  • TwelveData API Key: Free key from twelvedata.com used as high-quality secondary OHLC chart data or for symbols unavailable on Yahoo Finance (such as XAU/USD or BCO/USD).
  • Stock Alerts: Trigger screen flashing and an audible beep using < or > operators:
    • Example: TSLA > 300, BTC-USD < 45000
  • Custom Display Names: Rename tickers on screen using the >> operator:
    • Example: BTC-USD >> BITCOIN, GC=F >> GOLD

4. Sports Tracker

Track live games and scores using 2–4 letter city or team codes.

  • NBA / EPL / NFL / NHL / MLB: Enter comma-separated team codes (e.g., TOR, LAL, GSW or ARS, LIV, MUN) or enter ALL to track every live game in that league. See the full List of Team Codes.
  • Cricket Team or Series: Search by country or tournament keywords such as ENGLAND, ICC, or TOP.

5. Commute Configuration

Calculates travel time via the Google Routes API (How to get a Google API key for free).

  • Google Routes API Key: Required for commute calculations.
  • Origin / Destination: Enter street addresses or latitude/longitude coordinates.
  • Transport Mode: Select Car, Bus, Rail, or Train.
  • Active Window: Sets the hours (0–23) when commute info displays (e.g., 7 to 9 for a morning commute).
  • Station Address: Shown when Train is selected; enter your station for Park & Ride estimates.

6. City Weather

  • City Weather: Enter as City, CountryCode (e.g., Toronto, CA or London, GB).
  • Temp Units: Select Celsius (°C) or Fahrenheit (°F).
  • Timezone: Enter your UTC offset (e.g., -5 for EST, 0 for GMT).

7. Message Configuration

Configure up to 3 custom rows of text or live feeds.

  • Mode: Choose Text (static message) or RSS (scrolling feed).
  • Value: Enter custom text or a full RSS feed URL (e.g., https://feeds.bbci.co.uk/news/rss.xml).
  • Color: Pick the text color for that row using the color picker.

8. Focus Timer (Pomodoro)

  • Work (min): Focus session length in minutes (default: 25).
  • Break (min): Rest session length in minutes (default: 5).

9. Brightness & Schedule

  • Brightness Slider: Controls master LED intensity (5–255).
  • Night Mode (Checkbox): Enables automatic scheduled dimming.
  • Dim Between: Sets start and end hours (e.g., 22 to 7).
  • Night Brightness: Sets the reduced brightness level during the night window.

10. Cycle Durations

Controls how many seconds each module stays on screen per rotation.

  • Example: 60 for Stocks, 10 for Weather, 30 for NBA scores.

11. Upload Animation (GIF)

  • Matrix Size: Select your display resolution (128x64, 80x40, or 64x32).
  • Resize Mode:
    • Stretch: Scales the GIF to fill the entire display.
    • Fit: Preserves aspect ratio with black bars as needed.
    • Crop: Fills the screen by trimming edges.
  • Drop Zone: Upload or drag and drop a GIF to convert it into a matrix-ready animation.

12. Custom App

Run your own hosted app using any compatible WebP image (recommended for advanced users).

  • Run free Tronbyt server

13. System Controls

  • Save Configuration: Writes settings to the device microcontroller; most changes apply immediately.
  • Reboot Device: Performs a hardware restart (required after changing Logo or Sports settings).
